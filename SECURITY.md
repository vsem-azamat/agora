# Security Policy

Agora coordinates agents and can run commands on machines connected to it, so security reports are taken seriously.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through [GitHub Security Advisories](https://github.com/vsem-azamat/agora/security/advisories/new).

Include what you found, how to reproduce it, and the impact you expect. You will get an acknowledgement as soon as possible, and a fix or mitigation plan once the report is confirmed.

## Supported versions

Agora has no stable release yet. Fixes go to `main` and the next release.
