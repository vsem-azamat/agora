# Agora Documentation

Engineering documentation for Agora. What Agora does is specified in [`openspec/specs/`](../openspec/specs/README.md); if a document here and a spec disagree, the spec wins.

Every directory has a `README.md` index and every page starts with a breadcrumb line. Pages describe the current state only.
